# 6. ガバナンス

## DAO的参加の位置づけ

熊本災害支援DAOは、法人格や行政権限を代替するものではありません。支援者が復興分野について意見を共有し、プロジェクト改善へ参加するための公開コミュニティです。

本番候補の法的運営主体は、災害救援・復興支援を定款に持つ既存の認定NPO法人です。NPO法上の意思決定は社員総会、理事会、理事および監事が担い、ウォレット投票で代替しません。共同運営の責任分界は[システム構造](./architecture#認定npoを中心とする共同運営)に示します。

## 参考投票

玉垣SBT保有ウォレットは、道路・橋梁、上下水道、防災拠点などのテーマについて、クアドラティック・ボーティングによる非拘束の参考投票へ参加できます。

- 1ウォレットにつき各提案100ボイスクレジット
- 1〜10票を選び、票数の二乗（例：7票なら49クレジット）を消費
- 各提案への投票操作は1回とし、支援額やSBT保有数でクレジットを増やさない
- 投票結果は意見集約であり、行政判断を拘束しない
- 投票コントラクトは資金を保有・移動できない

この方式により、全員へ同じ発言予算を与えながら意見の強さを表現でき、強い票ほど限界費用が大きくなります。高額支援者による支配、ガバナンス攻撃、公共調達への不適切な介入を避けます。

## 運営上の役割

| 役割 | 主な責務 |
|---|---|
| 認定NPO法人 | 法的運営主体として規約、寄附成立、会計、理事会決議、問い合わせ、事業者・県との契約 |
| NPO財務マルチシグ署名者 | 理事会等の決裁に基づく集約送金。提案・照合・署名を分離 |
| 熊本県または委任報告者 | 受領確認、復興報告 |
| 登録金融・決済事業者 | 登録範囲内のJPYC管理・円転、AML/CFT、制裁対応、銀行送金 |
| 株式会社等の技術受託者 | コントラクト、インデクサー、公開UI、監視。支援金を所有・単独管理しない |
| 支援者コミュニティ | 参考投票、改善提案、公開検証 |

## 変更管理

本番コントラクトの管理権限変更、資産追加、受領先変更にはマルチシグとタイムロックを要求します。緊急停止と通常変更の手続きを分離し、すべての操作を監査ログへ残します。

オンチェーン投票、マルチシグ署名、理事会決議はそれぞれ別の意味を持ちます。Councilの結果は理事会への参考資料、マルチシグは承認済み決裁の技術的執行、理事会は法人としての法的意思決定です。三者を同一視しません。
