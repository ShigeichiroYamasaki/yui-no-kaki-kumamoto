# 6. ガバナンス

## DAO的参加の位置づけ

結の垣のDAOは、法人格や行政権限を代替するものではありません。支援者が復興分野について意見を共有し、プロジェクト改善へ参加するための公開コミュニティです。

## 参考投票

玉垣SBT保有ウォレットは、道路・橋梁、上下水道、防災拠点などのテーマについて非拘束の参考投票へ参加できます。

- 1ウォレット1票
- 支援額による票数増加なし
- 投票結果は意見集約であり、行政判断を拘束しない
- 投票コントラクトは資金を保有・移動できない

この制約により、高額支援者による支配、ガバナンス攻撃、公共調達への不適切な介入を避けます。

## 運営上の役割

| 役割 | 主な責務 |
|---|---|
| 運営法人 | 規約、会計、問い合わせ、事業者契約 |
| トレジャリー署名者 | 多者承認による集約送金・緊急停止 |
| 熊本県または委任報告者 | 受領確認、復興報告 |
| 交換・決済事業者 | 円転、法令対応、銀行送金 |
| 技術運営者 | コントラクト、インデクサー、公開UI |
| 支援者コミュニティ | 参考投票、改善提案、公開検証 |

## 変更管理

本番コントラクトの管理権限変更、資産追加、受領先変更にはマルチシグとタイムロックを要求します。緊急停止と通常変更の手続きを分離し、すべての操作を監査ログへ残します。
