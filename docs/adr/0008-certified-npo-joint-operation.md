# ADR-0008: 認定NPOを法的主体とする共同運営

- 状態: Proposed
- 日付: 2026-08-03

## 文脈

法人格のないDAOは、利用規約、寄附契約、雇用・委託、税務、銀行口座、事故責任の主体になれない。一方、認定NPO、熊本県、金融事業者、株式会社のいずれか一者へ全機能を集中すると、次の問題が生じる。

- 熊本県がJPYCと秘密鍵を直接保有する場合、公金収納、歳入計上、指定金融機関、財務規則、鍵管理との調整が必要になる。
- 認定NPOが利用者のJPYCを預かり、交換・振替・媒介すれば、電子決済手段等取引業への該当性が問題になる。
- 株式会社が支援金を保有すると、株主利益、倒産隔離、手数料、寄附目的との利益相反が生じる。
- 金融事業者は規制金融機能に適するが、復興目的、支援者参加、NPO事業、行政判断の主体ではない。

## 決定

### 1. 法的運営主体

本番候補の法的運営主体は、災害救援・復興支援を定款に持ち、情報公開、区分会計、理事会、監事または外部監査の体制を備えた**既存の認定NPO法人**とする。具体的な法人は選定・合意前であり、本ADRは提携を表明しない。

DAOはNPO法人を置き換えない。Council投票は非拘束の参考情報であり、社員総会、理事会、理事、監事の法定権限、熊本県の行政判断を拘束しない。

### 2. 支援金の法的帰属

初期の本番候補では、支援トランザクションの成立時に資産が認定NPOへ無条件かつ確定的に帰属する「NPOへの支援」とする。

- 支援者別残高、預り口、交換、振替、後日の支援先選択を提供しない。
- 法令、規約または事故対応上必要な場合を除き、支援者の任意返金請求権を設けない。
- NPOが登録事業者を介して自己資産を円転し、円貨を熊本県へ別個に寄附する。
- UI、規約、会計、event、公開報告で「支援者が熊本県へ直接JPYCを送金した」と表示しない。
- 将来、熊本県が登録事業者を使う公式収納スキームを承認した場合は、資金帰属とコントラクト経路を新ADRで置き換える。

### 3. 規制金融機能の分離

JPYCの管理・円転・媒介・銀行送金のうち登録を要する機能は、対象業務、資産、チェーンについて必要な登録と管理態勢を持つ金融・決済事業者へ委ねる。認定NPOや技術受託者は、一般利用者向け交換、支援者別資産管理、任意の振替サービスを提供しない。

契約前に、資金決済法、犯罪収益移転防止法、外為・制裁、国外支援、アンホステッドウォレット、トラベルルールの適用を専門家、登録事業者、当局相談で確認する。「認定NPO」「ノンカストディ」「スマートコントラクト」という名称だけで登録不要とは判断しない。

### 4. 技術受託者の隔離

株式会社等の技術受託者は開発、保守、監視、障害対応を契約に基づき行うが、支援金・Vault残高の所有、単独の管理・送金・停止解除・受領先変更、支援金からの任意報酬控除、NPO理事会や県報告の代替権限を持たない。技術費は事前承認された別予算・別会計から支払う。

### 5. ロール対応

| オンチェーンロール | 本番候補の保有主体 |
|---|---|
| `DEFAULT_ADMIN_ROLE` | NPO設定管理マルチシグ＋timelock |
| `TREASURER_ROLE` | NPO財務マルチシグ。理事会等の決裁を執行 |
| `PAUSER_ROLE` | 独立した緊急停止担当 |
| `UNPAUSER_ROLE` | NPO設定管理マルチシグ等の別主体 |
| Registry reporter | NPO報告マルチシグ。県または委任先の原本を照合 |
| Council | 資金・管理ロールを一切保有しない |

初期デプロイヤEOAのロールを残さない。技術受託者が緊急対応へ参加する場合も、単独実行できない限定ロールと期限付き手続を用いる。

## 理由

認定NPOは災害支援、寄附受領、情報公開、市民参加の中心に適し、登録金融事業者はJPYCと円貨の規制境界、株式会社は技術提供、熊本県は公金受領と復興報告、Councilは非拘束参加にそれぞれ集中できる。法的意思決定、金融規制、技術運用、行政権限を分離することで、無登録業務、利益相反、鍵侵害、虚偽表示の影響を限定する。

## トレードオフ

- 契約、理事会決裁、金融事業者審査、県受納のため、処理時間と費用が増える。
- 支援者から県への直接寄附ではないため、表示、税務、寄附受領証明の扱いが異なる。
- 認定NPOの法定ガバナンスが優先され、オンチェーン投票を自動執行できない。
- 登録事業者が対応しないチェーン、資産、国外送信元を受け付けられない。

## 本番開始条件

- 具体的な認定NPOの理事会承認と、定款・事業計画・区分会計への適合確認
- 支援成立、資産帰属、返金、手数料、SBT、県との関係を定めた規約
- 資金決済法上の管理・媒介該当性に関する弁護士意見と必要な当局相談
- 対象チェーンと公式JPYCに対応する登録事業者との契約
- 熊本県による円貨寄附の受納手順、名称使用、報告連携の書面合意
- NPO・金融事業者・技術受託者・県の責任分界、障害・返金・凍結runbook
- NPOマルチシグとtimelockへのロール移管、個人EOAと技術受託者の過剰権限削除
- JPYC受領から円転、県口座入金、Registry公開までの少額端間試験
- 会計・税務・AML/CFT・個人情報・表示について専門家確認

## 結果

具体的な認定NPO、登録事業者、熊本県との合意が成立するまで、この共同運営モデルは提案であり、Sepoliaデモは実資金を受け付けない。既存コードで初期adminが持つロールは本番運営体制を表さず、本番デプロイ後のロール移管を必須とする。
