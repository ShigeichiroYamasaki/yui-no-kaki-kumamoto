# ADR-0005: 個人情報と公開データを分離する

- 状態: Accepted
- 日付: 2026-07-31
- 更新日: 2026-08-05

## 決定

本番系では、氏名、住所、メール、IPアドレス、正確な位置情報、本人確認情報をオンチェーンに保存しない。公開名・国・メッセージは、撤回可能なオフチェーンデータとして管理する。

画像付きSBTの実現可能性を検証するtestnetデモに限り、支援者が送金前のプレビューを確認し、永続公開へ明示的に同意した場合、本人が決めた表示名と任意の奉納メッセージをSBTのオンチェーンSVGへ記録できる。表示名の初期値は空欄とし、実名またはニックネームを本人が入力する。金額表示は選択式とする。住所、メール、電話番号、IPアドレス、正確な位置情報、本人確認情報は、デモでも記録しない。

コントラクトは文字数と制御文字を検査するが、入力内容が実名か、第三者の個人情報を含むかは判定できない。UIで不可逆性と第三者情報の入力禁止を明示する。画像付きオンチェーンメタデータを本番へ採用する場合は、法務・プライバシー影響評価と関係者合意を別途必要とする。

## 理由

ブロックチェーンは削除・訂正が困難であり、ウォレットと個人情報の結合による追跡リスクがある。一方、デモでは玉垣画像がSBT単体で再現できることも検証対象であるため、環境、同意、入力範囲を限定した例外として扱う。

## 結果

本番系のオフチェーン公開表示を撤回しても、オンチェーンの支援イベント自体は残る。testnetデモでSBT画像へ記録した表示名・メッセージは撤回、訂正、非公開化できない。`showAmount=false`の場合はSVGとtoken metadataのAmount属性から金額を除外するが、`SupportReceived`イベントの資産と実受領額は公開されたままであり、匿名化機能ではない。UIは送信前にこの違いを説明し、同意がない場合は送信操作を有効にしない。
