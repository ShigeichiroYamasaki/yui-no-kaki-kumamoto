# ADR-0005: 個人情報と公開データを分離する

- 状態: Accepted
- 日付: 2026-07-31

## 決定

オンチェーンに氏名、住所、メール、IPアドレス、正確な位置情報、本人確認情報を保存しない。

公開可能な項目は、ウォレット、任意公開名、任意申告の国コード、金額または金額帯、メッセージのハッシュ、SBT、集約送金ID、公開報告ハッシュに限定する。公開名・国・メッセージは撤回可能なオフチェーンデータとして管理する。

## 理由

ブロックチェーンは削除・訂正が困難であり、ウォレットと個人情報の結合による追跡リスクがあるため。

## 結果

公開表示を撤回してもオンチェーンの支援イベント自体は残る。UIはこの違いを支援者へ説明する必要がある。
