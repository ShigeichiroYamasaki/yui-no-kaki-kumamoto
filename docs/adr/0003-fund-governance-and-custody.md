# ADR-0003: 資金管理とDAOガバナンスを分離する

- 状態: Proposed
- 日付: 2026-07-31

## 決定

資金移動はマルチシグ管理の`RecoverySupportVault`に限定し、DAO投票は`RecoverySupportCouncil`による非拘束の参考投票とする。

トレジャリーは任意送金先を許さず、熊本県が正式指定した受領先だけへ送金する。投票コントラクトには資金移動、任意コール、アップグレード権限を付与しない。

## 理由

寄附額による支配、投資性、公共予算への不適切な介入、ガバナンス攻撃を避けながら、支援者の参加感と透明性を提供するため。
