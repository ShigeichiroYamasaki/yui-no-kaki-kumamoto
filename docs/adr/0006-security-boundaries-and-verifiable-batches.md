# ADR-0006: 資金系を分離し、検証可能な送金バッチを採用する

- 状態: Proposed
- 日付: 2026-08-01
- 更新日: 2026-08-03

## 文脈

復興支援システムでは、受付Vaultへ資金が集中し、管理鍵、財務鍵、報告者鍵、公開サイトのいずれかが侵害される可能性がある。また、受付イベントと県への集約送金をバッチIDだけで結ぶ構造では、個々の支援がどの送金へ含まれたかを第三者が検証できない。

## 決定

### 資金滞留の最小化

- `RecoverySupportVault`を長期保管庫にせず、残高または経過時間の閾値で、熊本県災害支援口座への円貨送金契約と結び付いた登録済み事業者入金先へ送金する。
- Vault残高上限と運用上の送金頻度を本番開始前に決定する。
- 復興支援金と運営費を別コントラクト、別口座、別会計で管理する。

### 権限と鍵の分離

- 設定管理、財務送金、緊急停止、停止解除、県受領確認、復興報告を別ロールへ分離する。
- 受領先変更、許可資産追加、ロール変更にはマルチシグとタイムロックを要求する。
- 緊急停止は即時実行可能とし、停止解除には複数主体の承認を要求する。
- DAO投票コントラクトへ資金系のロールまたはアップグレード権限を付与しない。

### 検証可能な送金バッチ

- 各バッチへ対象`supportId`一覧のMerkle root、件数、資産別数量、円転確定額、明示手数料、県送金額、前バッチハッシュ、証憑ハッシュを関連付ける。
- 各バッチへ、事業者名、チェーン、登録済み入金アドレス、銀行振込先を特定する県の口座指定書hash、事業者受付番号、見積有効期限を含む決済指図hashを関連付ける。銀行口座番号そのものは公開チェーンへ記録しない。
- 支援者が自身の`supportId`についてMerkle proofを取得し、包含を検証できるようにする。
- 同一`supportId`を複数バッチへ含めない不変条件をインデクサーと監査処理で検証する。
- バッチ確定後の訂正は上書きせず、取消または後継バッチとして履歴を残す。

### 公開読み取り系の分離

- 本番画面はチェーン全履歴をブラウザから直接集計しない。
- 複数RPC、再編成対応インデクサー、検証可能な集計DB、読み取り専用APIを使用する。
- 確認中と確定済み、最終同期ブロック、最終同期時刻、障害状態を公開する。
- デモで採用するRPC上限以下の分割`eth_getLogs`は縮退策であり、本番Indexerの代替にしない。chain別RPC、manifest、障害表示は[ADR-0010](./0010-multichain-demo-deployment-and-observability.md)に従う。

### 参考投票の隔離

- 投票資格を提案開始時点のSBT保有状態でスナップショットする。
- 投票結果を自動執行せず、熊本県の判断を拘束しない。
- 複数ウォレット攻撃を完全には排除できないことを表示し、異常検知と任意の人間性証明を追加検討する。

## 理由

単一の防御機構に依存せず、侵害範囲を限定するため。Vaultに保持する価値を小さくし、重要権限を分散し、支援から県受領までを暗号学的に検証可能にすることで、資金損失と説明責任上の不正の両方を抑制する。

## トレードオフ

定期送金、Merkle tree生成、インデクサー、複数署名、タイムロックにより、運用コストと実装複雑性が増加する。少額で頻繁な送金は手数料を増やすため、残高上限、時間上限、手数料のバランスを運用設計で決める必要がある。

## 現行実装との差

強化版プロトタイプは、`batchId`再利用拒否、Merkle rootと決済指図hash、期限、資産別残高・batch・日次上限、beneficiaryの二段階変更と2日待機、pause/unpauseロール分離を実装した。最大滞留時間、supportIdの重複なきMerkle包含のオンチェーン検証、管理ロール自体のtimelock、独立した組織マルチシグは未実装であり、デプロイ時の上限初期値も本番値へ設定し直す必要がある。

攻撃だけでなく誤操作と内部不正を含む具体的な制御は[ADR-0007](./0007-threat-model-and-human-error-controls.md)に従う。

## 本番移行条件

- Vault残高上限と最大滞留時間の決定
- マルチシグ署名者、閾値、代替署名者の決定
- タイムロック時間と緊急時手続の決定
- バッチMerkle proofの生成・公開・検証試験
- チェーン再編成を含むインデクサー再同期試験
- 管理鍵侵害、財務鍵侵害、誤送金を想定した対応訓練
- 事業者入金先アドレスと熊本県災害支援口座の二経路照合、少額疎通試験、名義確認
