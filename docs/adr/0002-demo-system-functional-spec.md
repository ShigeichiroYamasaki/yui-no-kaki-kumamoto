# ADR-0002: デモ系の機能仕様

- 状態: Accepted
- 日付: 2026-07-31

## 文脈

熊本県、JPYC、交換・決済事業者、運営法人との調整前に、提案全体を安全に説明できる動作デモが必要である。

## 決定

デモ系は本番と同じ概念モデルを用いるが、実資産・実行政システムから完全に分離する。

### D-01 疑似支援

- JPYCまたはETH、金額、国、表示名、メッセージを入力できる。
- 実ウォレット接続、署名、送金を行わない。
- 実行時にサンプル玉垣、統計、最新活動を即時更新する。
- 常時「INTERACTIVE PROTOTYPE」を表示する。

### D-02 ダッシュボード

- 累計支援額、支援ウォレット、支援件数、国・地域数を表示する。
- 国別分布、ランキング、14日間推移を表示する。
- ETH円換算値は説明用固定値と明示する。

### D-03 資金フロー

- 集約、円転、熊本県受領をボタン操作で段階的に再現する。
- デモ受領番号とデモ証憑ハッシュを表示する。
- 実銀行口座・実交換所・実JPYCへ接続しない。

### D-04 復興報告

- 県担当者デモ画面から事業と進捗率、報告文を変更できる。
- 変更はブラウザ内状態だけに反映し、永続保存しない。
- 熊本県による承認済みと誤認させる表現を避ける。

### D-05 コントラクトデモ

- Hardhatローカルネットワークでは`MockJPYC`を使用できる。
- 本番モジュールとデモモジュールを分離する。
- デモ用鍵、アドレス、取引を本番へ流用しない。

## 受入条件

- 支援疑似実行後に玉垣と累計値が更新される。
- 円転と県受領の状態遷移を再現できる。
- 復興報告更新後に事業カードが更新される。
- 画面とREADMEで実資金を扱わない旨が確認できる。
- Hardhatテストが全件成功する。

## 結果

関係者は提案の一連の流れを体験できる。デモの結果は法的合意、金融取引、熊本県の受領を証明しない。
