# Sepolia / Base Sepolia デモ集計

Ethereum SepoliaとBase Sepoliaの支援額を一つの表の2行に表示し、両chainの玉垣SBTと支援履歴をそれぞれ一箇所へ統合します。玉垣は熊本城を囲む俯瞰、100本単位の区画、個別画像の順に確認できます。ウォレット接続または検索から自分の玉垣を見つけ、共有URLを作成できます。各項目にはchain情報を残し、異なるchainの金額やSBTを混同しません。
