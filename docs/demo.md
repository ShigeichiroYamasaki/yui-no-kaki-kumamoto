# Sepolia / Base Sepolia 支援デモ

ウォレットからEthereum SepoliaまたはBase Sepoliaのテスト用ETH・MockJPYCを送信し、譲渡不能な玉垣SBTが発行される一連の流れを確認できます。Base SepoliaはコントラクトアドレスがGitHub Pagesへ設定された後にネットワーク選択欄へ表示されます。

署名内容、JPYCの利用承認、確認状態、SBTの確認方法は[ウォレット利用体験](./wallet-experience.md)で説明しています。

発行後は[デモ集計ページ](./demo-status.md)で支援履歴と取得されたSBTを確認できます。
